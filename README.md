# 별조각 낙하 ✦

밤하늘에서 떨어지는 별조각을 쌓아 줄을 지우는 오리지널 낙하 블록 퍼즐 게임입니다.
HTML, CSS, JavaScript만으로 만들었고 설치할 것이 없습니다.

## 실행 방법
`index.html` 파일을 브라우저로 열면 바로 플레이할 수 있습니다.

## 규칙
- 조각은 2칸, 3칸, 5칸짜리 7가지 모양(쌍둥이, 막대, 꺾쇠, 십자, 컵, 계단, 큰꺾쇠)이 나옵니다.
- 가로 한 줄을 꽉 채우면 그 줄이 사라지고 점수를 얻습니다.
- 한 번에 여러 줄을 지우거나, 조각을 놓을 때마다 연속으로 줄을 지우면(콤보) 점수가 커집니다.
- 가끔 조각에 ✦ 별 칸이 들어 있습니다. 별이 있는 줄을 지우면 보너스 점수를 받습니다.
- 10줄마다 단계가 오르고 조각이 빨리 떨어집니다.

## 조작법
| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| ↑ | 회전 |
| ↓ | 한 칸 내리기 |
| 스페이스 | 바로 떨어뜨리기 |
| P | 일시정지 |

휴대폰에서는 화면 아래 버튼으로 조작합니다.

## 파일 구성
- `index.html` 화면 구조
- `style.css` 밤하늘 테마 꾸미기
- `game.js` 게임 규칙과 동작
